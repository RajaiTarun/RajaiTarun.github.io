The Great Box Rush 📦

50 boxes. 200 cats. What could go wrong?

Boxes left50
2 cats, 1 box0
Sulking 😾0

Every cat checks for a free box, then jumps in a bit later. No lock.

Same bug as an oversold hoodie, with more fur. MerchFlow fixes it with a real lock.

What's inside

  • Valkey (Redis) distributed locks: SET NX PX plus a token-bound Lua release, and atomic MongoDB stock decrements
  • Saga pattern with retry-with-backoff compensating transactions when payment fails
  • Idempotency keys so a double-click never orders twice
  • Polyglot data: PostgreSQL for orders, MongoDB for the catalog, RabbitMQ for notifications
  • Zero-trust gateway with JWT and RBAC. Found and fixed an IDOR and a cache-key bug
  • React 19 SPA, Docker, and all 6 services deployed on Render

POSIX Shell

GitHub ↗

A Unix shell written from scratch in C++. No bash underneath, just fork, exec, pipe, dup2 and a lot of careful signal handling.

What's inside

            
    
              
  • N-stage pipelines and < > >> redirection, via chained pipe + dup2
    • 
              
  • Job control: foreground and background jobs, with zombies reaped by waitpid(-1, WNOHANG)
    • 
              
  • Async-signal-safe Ctrl+C handling. Ctrl+Z suspends only the child, never the shell
    • 
              
  • Built-ins including pinfo, which reads live /proc/<pid> data
